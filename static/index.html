      Security

      Shows the lock screen. Anyone at the computer will need your password or PIN. (On a Mac this sleeps the display; set "Require password" to Immediately.)

      Needs your PIN and authenticator code. Windows shows a 30-second warning first, so you can still cancel. After a restart, remote access returns once someone signs in to Windows.

      Peek

      Stops Peek and remote access completely, for example before an online exam. It stays off, even after restarts, until you run resume-peek (.bat on Windows, .sh on Mac) on the PC. Needs the code from your authenticator app.
